## docs

Напиши раздел документации «Аутентификация» для API сервиса бронирования столиков. Токен получают запросом POST /v2/auth/token с полями client_id и client_secret в теле. Токен живёт 60 минут, передаётся в заголовке Authorization: Bearer <token>. При истечении API отвечает 401 с кодом token_expired, нужно запросить новый токен. Лимит 10 запросов на получение токена в минуту, при превышении 429. Пример на curl. Только текст документации, без пояснений.
