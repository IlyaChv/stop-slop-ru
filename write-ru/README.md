# write-ru

Скилл для написания текстов на живом русском языке.

Парный скилл к [stop-slop-ru](../stop-slop-ru). Этот пишет с нуля, тот проверяет готовое.

## Что это

`write-ru` создаёт русский текст и задаёт его голос. Метод собран из трёх источников: механика канцелярита по Норе Галь, работа с фактурой по Максиму Ильяхову, каркас скилла по английскому [Stop Slop](https://github.com/hvpandya/stop-slop) Хардика Пандьи.

## Чем отличается от `stop-slop-ru`

| | `write-ru` | `stop-slop-ru` |
|---|---|---|
| Работа | Пишет с нуля | Проверяет готовое |
| Голос | Задаёт свой | Сохраняет авторский |
| Справочники | Позитивная техника | Каталог симптомов |
| Результат | Текст | Отчёт, потом правка по команде |

Правка чужого черновика это работа `stop-slop-ru`. Причина: там главное ограничение — сохранить голос автора, а писатель голос задаёт сам и чужие тексты причешет под себя.

## Структура

```
write-ru/
├── SKILL.md
├── scripts/
│   └── check.py        # Самопроверка черновика по стоп-словам
├── references/
│   ├── technique.md    # Как строится живая русская фраза
│   ├── stop-words.md   # Чего не пишем
│   ├── domains.md      # Профили доменов
│   └── examples.md     # Как фактура превращается в текст
├── evals/              # Тестовые брифы и ожидания
├── README.md
└── LICENSE
```

## Скрипт

```
python scripts/check.py черновик.md
```

Тот же скрипт, что у `stop-slop-ru`, но читает `references/stop-words.md`. Показывает стоп-фразы с номером абзаца, считает частицы и числа, ловит заголовки С Больших Букв и бинарные контрасты. Только стандартная библиотека Python.

## Главное правило

Без фактуры не пишем. Машинный текст читается как машинный чаще всего потому, что писать не о чем и пустоту забивают словами. Стиль вторичен.

Скилл проверяет, есть ли число, имя, случай или конкретное действие продукта. Если нет, он задаёт вопросы вместо того, чтобы сочинять воду.

## Домены

| Домен | Режим |
|-------|-------|
| Лендинги, кейсы, коммерческие предложения | Полный |
| Статьи, блог, соцсети, рассылки | Полный |
| Деловая переписка | Полный |
| Техническая документация | С поправками: списки и повторы разрешены, термины неприкосновенны |
| Научные и аналитические тексты | С поправками: пассив нормативен |
| Юридические и медицинские тексты | С поправками: точность важнее живости |
| Художественная проза | Не применять |

## Установка

**Claude Code.** Скопируйте папку в `~/.claude/skills/` или в `.claude/skills/` проекта.

**Claude Projects.** Загрузите `SKILL.md` и файлы из `references/` в базу знаний.

**API.** Вставьте `SKILL.md` в системный промпт, справочники подгружайте по необходимости.
