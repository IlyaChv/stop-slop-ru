# Русские скиллы для текста: stop-slop-ru и write-ru

Два скилла для Claude Code и других LLM-агентов. Один проверяет готовый русский текст на следы ИИ и слабое письмо, другой пишет русский текст с нуля так, чтобы этих следов не было.

| Скилл | Что делает | Когда вызывать |
|-------|------------|----------------|
| [stop-slop-ru](stop-slop-ru/) | Ревьюер. Определяет домен, считает маркеры скриптом, выдаёт отчёт с весом каждой находки и риском искажения смысла. Правит только по отдельной команде и сохраняет голос автора | «Проверь», «оцени», «причеши», «это нейросеть писала?» |
| [write-ru](write-ru/) | Писатель. Не пишет без фактуры, строит фразу вокруг деятеля и глагола, держит неровный ритм и частицы, помечает дыры в брифе вместо того, чтобы их додумывать | «Напиши лендинг», «напиши письмо», «сделай раздел документации» |

Скиллы парные, но независимые: каждая папка работает сама по себе. Стоп-слова продублированы намеренно.

## Почему два, а не один

Ревьюер работает с чужим текстом, и его главное ограничение сохранить голос автора. Писатель голос задаёт сам. Если отдать правку писателю, он причешет все чужие тексты под себя, и получится ровно тот одинаковый «инфостиль», за который его и критикуют.

## Что внутри метода

- Плотность вместо наличия. Один канцеляризм ничего не доказывает, живой бюрократ пишет неровно. Машина держит ровную плотность через весь текст, поэтому вердикт учитывает распределение по абзацам и контрпризнаки: частицы, идиомы, конкретику, брошенную мысль.
- Семь профилей доменов. В научном тексте пассив норма, в документации термины неприкосновенны, в договоре у каждой находки стоит риск искажения, а «вправе» и «обязан» не синонимы. Художественная проза выключена целиком.
- Скрипт `scripts/check.py` в обеих папках. Только стандартная библиотека Python, читает каталог маркеров из `references/`, печатает находки по абзацам, плотность на тысячу знаков, распределение и структурные признаки. Синтаксис и смысл остаются модели, и в отчёте видно, что добавила она.
- Тире не запрещено. Для русского пунктуация слабый признак генерации, это показывают работы по детекции ИИ-текста. Грамматическое тире остаётся, режется только драматическое.

## Установка

Скопируйте нужную папку целиком в `~/.claude/skills/` или в `.claude/skills/` проекта:

```
~/.claude/skills/stop-slop-ru/
~/.claude/skills/write-ru/
```

Для Claude Projects загрузите `SKILL.md` и файлы из `references/` в базу знаний. Для API вставьте `SKILL.md` в системный промпт, справочники подгружайте по необходимости. Скрипт в этих режимах не запустится, скиллы это учитывают: без Python модель считает по каталогу руками и говорит об этом в отчёте.

## Проверить скрипт без агента

```
python stop-slop-ru/scripts/check.py текст.md --domain full
python write-ru/scripts/check.py черновик.md
```

Профили ревьюера: `full`, `post`, `tech`, `science`, `legal`. Флаг `--json` даёт машинный вывод.

## Тесты

В `evals/` каждой папки лежат тестовые задания и ожидания: сгенерированный лендинг, письмо бюрократа, живой пост, договор с инструкцией к препарату, гладкая статья для блога, отрывок прозы, три брифа для писателя. По ним калибровались пороги плотности, и по ним можно проверить любую правку каталога: прогнать задание через скилл и сверить с `evals.json`.

## Источники

- Нора Галь, «Слово живое и мёртвое». Механика канцелярита.
- Максим Ильяхов и «Главред». Стоп-слова, фактура, и его же предупреждение о том, что инфостиль сам стал штампом.
- Русская Википедия, «Признаки сгенерированности текста».
- Работы по детекции сгенерированного текста на русском (AINL-Eval 2025, DependencyAI).
- [Stop Slop](https://github.com/hvpandya/stop-slop) Хардика Пандьи: английский оригинал, от которого взят каркас. Русская версия не перевод: каталог маркеров собран заново под язык, добавлены профили доменов, вес находок, риск искажения смысла и скрипт подсчёта.
