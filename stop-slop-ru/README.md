# stop-slop-ru

Скилл, который проверяет русский текст на следы ИИ и слабое письмо.

Парный скилл к [write-ru](../write-ru). Этот проверяет готовое, тот пишет с нуля.

Русская переработка [Stop Slop](https://github.com/hvpandya/stop-slop) Хардика Пандьи. Не перевод: каталог маркеров собран заново под русский язык, добавлены профили доменов и отчёт с весом находок.

## Что делает

1. Определяет домен текста и говорит, в каком режиме работает.
2. Считает лексические маркеры скриптом `scripts/check.py`: плотность на тысячу знаков, распределение по абзацам, контрпризнаки, структуру. Цифры воспроизводимы.
3. Дочитывает глазами то, что скрипт не видит: нанизывание падежей, спрятанного деятеля, воду, композицию.
4. Выписывает утверждения, которые нужно проверить руками: круглые числа, безымянные исследования, ссылки без выходных данных.
5. Выдаёт отчёт: вердикт, таблица находок, разбивка по типам, список для проверки.
6. Останавливается. Правит только по отдельной команде и с сохранением голоса автора.

## Скрипт

```
python scripts/check.py текст.md --domain full
```

Только стандартная библиотека Python. Читает каталог из `references/markers.md`, поэтому новая фраза в каталоге сразу попадает в подсчёт. Профили: `full`, `post`, `tech`, `science`, `legal`. Флаг `--json` даёт машинный вывод.

Скрипт считает лексику и структуру. Синтаксис, смысл и факты остаются модели, и в отчёте видно, что добавила она.

## Вес находки

| Вес | Что означает | Примеры |
|-----|--------------|---------|
| Высокий | Почти наверняка машина | Артефакты чат-бота, Заголовки С Больших Букв, «В современном мире», меризм «от X до Y» |
| Средний | Человек тоже так пишет, выдаёт плотность | Канцелярит, пассив, отглагольные существительные, нанизывание падежей, аналитический туман, дидактика |
| Низкий | Считается только в совокупности | Правило трёх, ровный ритм, одинаковая длина абзацев |

Плотность важнее наличия. Один канцеляризм не доказывает ничего: живой человек пишет неровно. Машина держит ровную плотность через весь текст. Поэтому вердикт «похоже на машину» требует либо находки высокого веса, либо плотности выше 6 при ровном распределении и без контрпризнаков вроде частиц и конкретики. Бюрократ с плотностью 10 получает «спорно» и диагноз «канцелярит».

## Риск искажения

Отдельная колонка в отчёте: нет, возможен, высокий. В юридических и медицинских текстах обязательна для каждой находки.

При высоком риске скилл показывает замену, но не применяет её даже по команде «правь». «Вправе» и «обязан» не синонимы. «Вызывает» и «может вызывать» не синонимы.

## Домены

| Домен | Режим |
|-------|-------|
| Лендинги, кейсы, коммерческие предложения | Полный |
| Статьи, блог, соцсети, рассылки | Полный |
| Деловая переписка и документы | Полный |
| Техническая документация | С поправками: термины и списки неприкосновенны |
| Научные и аналитические тексты | С поправками: пассив нормативен |
| Юридические и медицинские тексты | С поправками: риск искажения у каждой находки |
| Художественная проза | Не применять |

## Чем отличается от английского оригинала

| Оригинал | Русская версия |
|----------|----------------|
| Полный запрет длинного тире | Грамматическое тире остаётся. Для русского пунктуация слабый маркер, это показывают работы по детекции ИИ-текста |
| Запрет всех наречий на -ly | Режем усилители и хеджи, наречия с фактом оставляем |
| Запрет пассива | Плюс безличные обороты, отглагольные существительные, нанизывание родительных падежей |
| Общий список фраз | Отдельный слой канцелярита, отдельный слой типографики, отдельный слой артефактов чат-бота |
| Шкала из ощущений | Плотность на тысячу знаков считает скрипт, вердикт учитывает распределение по абзацам и контрпризнаки, вместо баллов разбивка по типам |
| Без доменов | Семь профилей с разными правилами |

## Источники метода

- Нора Галь, «Слово живое и мёртвое». Механика канцелярита: глагол вытесняется существительным, нанизываются родительные падежи, актив заменяется пассивом.
- Максим Ильяхов и «Главред». Таксономия стоп-слов, работа с фактурой, а также его собственное предупреждение о том, что инфостиль сам стал штампом.
- Русская Википедия, «Признаки сгенерированности текста». Живой реестр маркеров: слова-отпечатки, рекламный слой, артефакты диалога, типографика.
- Работы по детекции сгенерированного текста на русском (AINL-Eval 2025, DependencyAI). Вывод: для русского пунктуация слабый признак, работают синтаксические связи.

## Установка

**Claude Code.** Скопируйте папку в `~/.claude/skills/` или в `.claude/skills/` проекта.

**Claude Projects.** Загрузите `SKILL.md` и файлы из `references/` в базу знаний.

**API.** Вставьте `SKILL.md` в системный промпт, справочники подгружайте по необходимости.
